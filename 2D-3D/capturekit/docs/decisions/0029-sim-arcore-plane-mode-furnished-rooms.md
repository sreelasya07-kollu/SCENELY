# 0029: Simulator "arcore" plane mode and the furnished4 / furnishedL rooms

Status: accepted (2026-11-18, brief real-room-fix T4). The ideal sim emitted one growing plane per true wall, so it never exercised what broke on the device (RCA: plane fragments, re-ids, stale subsumed planes). New `sim::Config::planes` ("" = room default, "ideal", "arcore"); only `furnished4` and `furnishedL` default to "arcore", so every existing room, golden and guide-eval number is unchanged.
Arcore mode (own RNG `seed * 104729 + 31`; walker/sensor draws untouched): wall planes are tracks fixed at start, one per along-wall fragment between furniture standing against the wall (< 0.3 m off it, >= 0.3 m wide; fragments < 0.3 m dropped); a fragment > 2 m starts as two halves (p 0.5) that merge once both were emitted 8 times (lower id takes the union, the other id goes stale = subsumed, no bundle field). A track is detected once >= 10 points cover >= 0.2 x 0.2 m of it (0.25 m along-wall bins); each emission after 3 may re-id (p 0.01/s, old id stale). Every id draws 2-4 deg yaw jitter (random sign) and +-2 cm offset. One textureless wall per room: no plane, 35 % of its points. Floor/ceiling/table tops as in "ideal". Report gains `sim_planes`.
Rooms: furnished4 = 5 x 4.5 m, sofa (wall 0), wardrobe 2 m tall (wall 1), bed head (wall 3), wall 2 textureless -> fragments [2,2,0,2]; furnishedL = the L room, sofa (wall 0), bed (wall 1), wardrobe (wall 5), wall 4 textureless -> [2,2,1,1,0,1]. All numbers are starting guesses; retune against scan_20261117_215819 plane statistics.

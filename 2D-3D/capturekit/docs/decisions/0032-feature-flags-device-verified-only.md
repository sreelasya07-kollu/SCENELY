# 0032: Default build shows only device-verified features; the rest sit behind FeatureFlags (issue #6)

Status: accepted (2026-11-19), issue RealKarthiksai/2D-3D#6. Supersedes ADR 0030 "detector default on" (classes, schema and display decisions of 0030 stand).
- Rule: a feature is ON by default only if it PASSed on the phone (docs/DEVICE_TEST_LOG.md); failed or never device-tested = OFF. Table: docs/STATUS.md section 0. Nothing is deleted: Step 4 found no symbol with zero references after gating (VoiceController, StateAnswers, UnderstandingView, RoomView, ChecklistView, DetectionOverlayView, RecalibrateOverlay, ObjectSummary are still referenced behind flags); `DebugFlags` was renamed (not deleted) to `FeatureFlags`.
- Mechanism: `dev.capturekit.capture.FeatureFlags` (lib, pure, unit-tested) generalises U11-A `DebugFlags`. Switches `guidance`, `detector`, `voice_commands`, `recalibrate_card` (all default 0) and `understanding 0|1|2`; set with `adb shell setprop debug.capturekit.<name> 1`, read only in debuggable builds, once per process (force-stop after setprop). Same defaults in both flavours. Junk/blank = default.
- Guidance gate: with `guidance` off only SLOW_DOWN, HOLD_STILL, RELOCALIZE, MORE_LIGHT, AIM_TEXTURED, RECALIBRATE are shown/spoken/felt (explicit list, not core priority: MORE_LIGHT is priority 1 but passed on device). The core still records every instruction in /events. Guidance off also hides the live room card, the weak-wall review sheet (an empty-scan notice stays, bug B5) and the Review room drawing.
- Detector off: no `guide.understanding` key, so no /ar/detections and no /guide/* outputs; no boxes chip, labels or "Found" row. Voice commands off: VoiceController is not built, Start asks no microphone permission. Recalibration card off (no device cover/uncover check yet); the core keyframe pause stays. Face redaction stays ON (unverified, H14): off would ship unblurred faces and break `redaction_mode=faces` bundles.
- Flip back: run the HUMAN_TESTS item listed per feature in STATUS.md section 0 on a device, log PASS in DEVICE_TEST_LOG.md, then change the default in `FeatureFlags.Flags`.

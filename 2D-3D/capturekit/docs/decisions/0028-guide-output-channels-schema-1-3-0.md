# 0028: derived /guide/labels, /guide/shell, /guide/gaps channels, schema 1.3.0

Status: accepted (2026-11-18). Part 2 and the e2e report need what the engine understood (objects, openings, room outline, missing areas) next to the raw streams. Settled earlier: outputs are the next free minor (ADR 0018 item 9).
- Three optional MCAP channels, one message each (`RoomLabels`, `RoomShell`, `RoomGaps`), world metres, plain value copies of guide::Object/Opening/ShellModel/Gap (no layout-model fields: real-room-fix keeps the schema out of that work). Written by Session only while `guide.understanding` > 0, when the published value changed (check every 1 s of event time) and once more at finalize, so the last record is the end state; empty content never starts a channel. Derived data: replay does not feed them back (no `ReplaySink` hook), `recover` copies them.
- Manifest stamps 1.3.0 only when at least one record exists, and adds `counts.guide_*` only then; every other bundle (goldens, sim, frozen-1.0.0) is byte-identical. Cost: 1.3.0 >= 1.2.0, so ADR 0020 consent/privacy rules apply; a session with understanding on and no consent keys fails CONSENT_MISSING, and the validator stays strict. Synthetic writers that go through Session (`ckit simulate-capture`, `ckit.simulate.simulate`) stamp placeholder keys (`consent_version` "synthetic", `consent_at` 1970-01-01T00:00:00Z, `redaction_mode` "none") when `guide.understanding` > 0 and the caller gave none; the core guide sim and guide-eval do not write bundles. C++ tests that run a Session with understanding on and check the validator must pass consent keys themselves.
- Validator (C++ semantic and Python): GUIDE_OUTPUT_BAD_VALUE (WARN), LABEL_WALL_UNKNOWN (INFO), counts parity. Surface classes (floor/wall/table per plane) are not a channel: `/ar/planes` keeps the platform kinds. `ckit e2e` reads the final `/guide/gaps` and scores missing-area recall against an optional truth file.
- Rejected: writing outputs into guidance_log.json (not time-aligned, no MCAP tooling); one combined channel (a change in one part would rewrite all).
